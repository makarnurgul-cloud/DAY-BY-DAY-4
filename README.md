# day by day ♡ — Өзіме уақыт

Қазақ тіліндегі жеке даму қосымшасы: күнделік, күнделікті әдеттер, мақсаттар, көңіл-күй, доспен тапсырма, статистика және әкімші шолуы.
Бұл қосымша пайдаланушының күнделікті өмірін жоспарлауға және уақытын тиімді пайдалануға көмектеседі. Сонымен қатар, адам өзінің жетістіктерін бақылап, күнделікті нәтижелерін талдай алады.

## Маңызды айырмашылықтар

Бұл жоба **Next.js емес**, **TanStack Start + React + TypeScript + Tailwind CSS** арқылы жасалған. App Router орнына TanStack файлдық беттері қолданылады. Талаптағы `NEXT_PUBLIC_*` айнымалыларының орнына `.env.example` ішіндегі `VITE_*` және сервер айнымалыларын пайдаланыңыз.

Деректер PostgreSQL мен Auth-та сақталады; localStorage тек кіру сессиясына арналған. Әкімші рөлі қауіпсіздік үшін `profiles.role` өрісінде емес, **`user_roles`** кестесінде сақталады. Өз профилін өңдеген пайдаланушы өзін әкімші ете алмайды.

## Дерекқор

База қосылған және SQL схема орындалған. Қайта орындаудың қажеті жоқ. More → Users арқылы пайдаланушылар мен Email/Google кіру баптауларын қараңыз. More → Database арқылы кестелерді қараңыз. Жаңа тіркелуші поштадағы растау сілтемесін басқаннан кейін кіре алады. Профиль тіркелген сәтте автоматты жасалады.

## VS Code-та іске қосу

1. Node.js 22 немесе жаңа нұсқасын орнатыңыз.
2. ZIP архивін шығарып, қалтаны VS Code-та ашыңыз.
3. Терминалда орындаңыз:

```sh
npm install
cp .env.example .env.local
npm run dev
```

Windows-та `.env.example` файлын көшіріп, көшірмесін `.env.local` деп атаңыз. Vite көрсеткен жергілікті мекенжайды ашыңыз.

4. `.env.local` ішіндегі төрт бос айнымалыны сол бір деректер жобасының URL және **жария** кілтімен толтырыңыз. Браузер мен сервер бір жобаға қарауы керек. `service_role` немесе құпия кілтті `VITE_*` айнымалысына жазбаңыз. Архивте нақты кілттер мен құпиялар жоқ. Бастапқы ортада бұл мәндер автоматты берілген; жүктелген көшірмеде қолмен баптау қажет.
5. Көшірмені бөлек PostgreSQL/Auth ортасына орналастырсаңыз, `supabase/schema.sql` файлын жаңа, бос ортаның SQL редакторында бір рет орындаңыз. Ол Auth-та `auth.users`, `auth.uid()` және `authenticated/service_role` рөлдері бар ортаға арналған. Жай PostgreSQL серверіне өзгеріссіз жарамайды. Кірудің email әдісін қосыңыз. Auth-та сайт URL-ін жергілікті мекенжайға қойып, растау және `/reset-password` мекенжайларын рұқсат етіңіз. Бастапқы орта үшін SQL әлдеқашан орындалған; бұл бөлек ортаға көшіру жолы ғана.
6. Google кіруі OAuth арқылы жұмыс істейді. Бөлек орналастырылған ортада бұл батырмалар сол қызметтің баптауы мен қолдауын қажет етеді; кәдімгі email/құпиясөз кіруі жобаның Auth баптауына тәуелді емес OAuth әдісін қолданбайды.

Архивте гүл суреті жергілікті `public/images/` файлымен бірге берілген; Бастапқы ортада актив сілтемесі қолданылған.

## Кестелер мен қолжетімділік

- `profiles`: аты және тіркелген күні. Өз профилін оқиды/жаңартады; әкімші барлық профильді оқиды.
- `user_roles`: `user` немесе `admin`; браузерге тек оқу рұқсаты берілген.
- `diary_entries`, `habits`, `habit_logs`, `goals`, `mood_logs`: пайдаланушы өз жазбаларын оқиды/өзгертеді; әкімші барлығын оқи алады.
- `shared_tasks`: иесі тапсырманы қосады және өзгертеді. Қатысушы тек өз орындау белгісін өзгертеді.
- `shared_task_members`: тек шақыру кодымен `join_shared_task` арқылы қосылады. Қатысушылар тізімін тапсырма иесі мен мүшелері оқиды.

Әкімші панелі `/admin` мекенжайында, тек оқуға арналған. Барлық ішкі беттер кірумен қорғалған. Оқу функциялары серверде сессияны тексереді; өзгерістерге база RLS қолданады. Үлкен кестелер 1000 жолдық бөліктермен толық оқылады.

## Алғашқы әкімшіні тағайындау

Автоматты әкімші жоқ. Сенімді жоба иесі жеке пайдаланушыны әкімші етуін сұрауы керек. Құқық тек қорғалған басқару құралымен `user_roles` кестесіне қосылады. Жаңа тіркелушілерге әрқашан `user` беріледі; профиль атында немесе пайдаланушы metadata-сында жазылған рөл ескерілмейді. Нақты пайдаланушыны оның рұқсатынсыз әкімші етпеңіз.

## Тексеру

```sh
npm test
```

Сынақтар маршрут, профиль триггері, гранттар, RLS сипаттамасы, рөл орны және есептеу ережелерін тексереді. Жұмыс кезінде нақты базаға күнделік, әдет, мақсат, көңіл-күй және ортақ тапсырма жазып, қайта жүктелгенде оқылуы тексерілді. Google сыртқы кіруі және поштаға келген сілтемелерді толық ашу жеке тексеруді қажет етеді.

## Негізгі файлдар

- `src/routes/`: кіру мен қорғалған беттер.
- `src/components/day/`: интерфейс.
- `src/lib/day.functions.ts`: қорғалған серверлік оқулар.
- `supabase/schema.sql`: кестелер, гранттар, RLS, триггерлер және шақыру функциясы.
- `drizzle/migrations/`: қолданылған өзгерістердің тарихы.
- `.env.example`: құпиясыз баптау үлгісі.

Құрастыру: `npm run build`. Жергілікті алдын ала көру: `npm run preview`. Бұл архив — бастапқы код, орнатылған пакеттер мен дайын құрастыру нәтижелері кірмейді.
